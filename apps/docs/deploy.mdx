# Deploy

MCPLib builds its API and web app separately. Choose a hosting platform that supports the Node.js runtime and configure the API, web app, and PostgreSQL database for your environment.

## Build

Run the workspace build from the repository root:

```bash
pnpm run build
```

The API uses an unbundled esbuild output and the web app uses Vite. The workspace build also builds shared packages.

## Configure the API

Set `DATABASE_URL`, `CORS_ORIGINS`, `WEB_APP_URL`, and `MCPLIB_SECRET_ENCRYPTION_KEY` in the API environment. Configure provider OAuth credentials only for integrations you enable. Keep secrets in the hosting platform's environment or secret manager.

## Configure the web app

Set `VITE_API_URL` to the public API origin before building the web app. Configure the API's `CORS_ORIGINS` to allow that web origin.

## Database

Provision PostgreSQL and apply the Prisma migrations for the environment before starting the API. Keep database credentials outside the repository.

For local environment setup, see [Quickstart](/quickstart).
